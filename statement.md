# Project Statement

## Project Title

Plant Disease Detection Using Computer Vision

## Problem Statement

Plant diseases can affect plant growth and crop production. Identifying diseases manually may require experience and proper knowledge.

This project aims to develop a simple computer vision-based prototype that allows users to upload a plant leaf image and view a possible health condition.

## Project Scope

The project focuses on creating a simple image-based plant health analysis application.

The current prototype includes:

- Plant leaf image upload
- Image display
- Basic image information
- Possible health result
- Basic suggestions

The current version is developed for educational purposes.

## Target Users

- Students
- Beginner programmers
- Farmers for basic educational reference
- People interested in plant health
- Computer vision learners

## High-Level Features

1. Upload a plant leaf image.
2. Display the uploaded image.
3. Show image format and dimensions.
4. Display a possible plant health condition.
5. Provide a basic suggestion.
6. Show a limitation notice.

## Expected Outcome

The expected outcome is a simple and user-friendly computer vision prototype that demonstrates the basic workflow of an image analysis application.

## Current Limitation

The current prototype does not use a trained machine learning model. Its result is only for demonstration and educational purposes.

## Future Enhancement

In the future, a trained deep learning model can be added to identify plant diseases more accurately.
