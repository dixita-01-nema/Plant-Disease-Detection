# Plant Disease Detection Using Computer Vision

## Project Overview

Plant Disease Detection is a computer vision-based application that allows users to upload a plant leaf image and view its possible health condition.

The application provides a simple interface for uploading an image, checking basic image details, and displaying a possible prediction result.

This project is developed as an educational prototype.

## Objectives

- To create a simple plant leaf image analysis application.
- To provide an easy image upload interface.
- To display basic image information.
- To show possible plant health conditions.
- To understand the basic workflow of a computer vision application.

## Features

- Upload plant leaf images.
- Supports JPG, JPEG, and PNG images.
- Displays the uploaded image.
- Displays image format and size.
- Shows a possible plant health result.
- Provides basic suggestions based on the result.
- Simple and user-friendly interface.

## Technologies Used

- Python
- Streamlit
- Pillow
- Computer Vision concepts
- Visual Studio Code

## Project Modules

### 1. Image Upload Module

Allows the user to upload a plant leaf image.

### 2. Image Analysis Module

Displays the uploaded image and basic information such as image format and image size.

### 3. Prediction Result Module

Displays a possible plant health condition and a basic suggestion.
